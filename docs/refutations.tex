\title{Two machine-checked refutations in the \Calc{} metatheory\\
  \large Lemma E.17 (Look completeness) and
  Theorem 4.6 (Completeness and optimality of subtyping)
  are false as stated}
\author{}
\date{}

\begin{document}
\maketitle

\begin{abstract}
  \noindent
  One subtyping configuration refutes both statements.  The declarative
  side of that configuration --- the solution, including the tag
  obligation it must discharge --- is a Coq term, not a prose argument;
  so is the non-existence of an algorithmic run.  No source program and no
  typing derivation is involved: both statements are about subtyping and
  the refutation stays there.

  The defect is localised to \emph{one} rule of constraint solving,
  \soleqlab{FlexR}, which discards information the algorithm has already
  computed.  Handing the algorithm the instantiation that information
  determines makes the run exist --- also machine-checked.  A repair is
  suggested at the end, together with what has to be checked before it is
  applied.

  Everything below is \texttt{Qed} and axiom-free
  (\texttt{Print Assumptions}: \emph{closed under the global context}).
\end{abstract}

\section{The configuration}\label{sec:config}
% =====================================================================

$\Theta_0$ holds exactly one flexible variable, \emph{undefined}:
\[
  \Theta_0 = \hat\beta
  \qquad
  \N = \TY
  \qquad
  \M = \FN\TC
  \qquad
  P_0 = (\forall \gamma.\gamma\to\gamma) \to \hat\beta
  \qquad
  P   = \forall \alpha.\alpha\to\alpha .
\]
The unresolved subject, the metasubstitution, the \sublab{ForallL}
instantiation and the counterpart are
\[
  S = \foralltag{\delta}\alpha.\alpha\to\alpha
  \quad
  \theta = [\hat\beta \mapsto \tunit\to\tunit]
  \quad
  \psi_a = \foralltag{\epsilon}\gamma.\gamma\to\gamma
  \quad
  \Psi_a = \epsilon
  \quad
  \bid{Q} = \inh{\forall\gamma.}(\gamma\to\gamma) \to (\tunit\to\tunit),
\]
so that $\erase{S} = P$ and $\Psi = \cdot$ is disjoint from $\Psi_a$.

Two features of $P_0$ are what everything turns on.
\begin{itemize}
\item Its \emph{domain} is a bare $\forall$.  An arrow-left is a
  \emph{consistency} position, and $\inh{\theta P_0}$ paints exactly the
  $\forall$s of $P_0$ inherited --- so this is the only position at which
  a guess's tag can be paid.
\item Its \emph{codomain} is a raw $\Theta_0$-flexible.  The algorithm has
  no inherited information there, whereas the declarative side reads
  $\theta\hat\beta = \tunit\to\tunit$.
\end{itemize}

\noindent
Both sections use the same declarative derivation, so we record it once.
Writing $\Theta_0,\gamma$ for $\Theta_0$ extended with the rigid $\gamma$:
\[\small
\inferrule*[Lab=\sublab{Arrow}]
{
  \inferrule*[Lab=\eqlab{ForallInh}]
  { \inferrule*[Lab=\eqlab{Arrow},\;\eqlab{Var}]
    { }
    { \typconsis[\cdot]{\Theta_0,\gamma}{\syn{\gamma\to\gamma}}
        {\bid{\gamma\to\gamma}} } }
  { \typconsis[\epsilon]{\Theta_0}{\syn{\psi_a}}
      {\inh{\forall\gamma.}\bid{\gamma\to\gamma}} }
  \\
  \inferrule*[Lab=\sublab{ForallL}]
  { \Theta_0\vdash\tags{\cdot}{\syn{\tunit}}
    \\
    \inferrule*[Lab=\sublab{Check}]
    { \typconsis[\cdot]{\Theta_0}{\syn{\tunit\to\tunit}}
        {\inh{\tunit\to\tunit}} }
    { \typsub[\TY][\TC][\cdot]{\Theta_0}{\syn{\tunit\to\tunit}}
        {\inh{\tunit\to\tunit}} } }
  { \typsub[\TY][\TC][\cdot]{\Theta_0}{\syn{\psi_a}}
      {\inh{\tunit\to\tunit}} }
}
{ \typsub[\TY][\FN\TC][\epsilon]{\Theta_0}
    {\syn{\psi_a}\to\syn{\psi_a}}{\bid{Q}} }
\tag{$\star$}\label{star}
\]
Read the tag index.  \sublab{Arrow} splits it as
$\Psi_1,\Psi_2 = \epsilon,\cdot$.  On the left, \eqlab{ForallInh} ---
the only rule in the system that puts a tag \emph{into} the index --- pays
$\epsilon$ against an \emph{inherited} $\forall$: this is the ``never
guess polymorphism out of thin air'' obligation, discharged rather than
assumed.  On the right the same guess is instantiated by \sublab{ForallL}
with the \emph{monotype} $\tunit$, whose tag set is empty, so nothing is
owed there.  (Coq: \coq{consis\_d}, \coq{refine\_dom\_d},
\coq{join\_cod\_d}.)

Finally $\inc[\theta]{\Theta_0}{\Theta_0}$ (\coq{inc\_d}) and the fill
$\Theta_0\vdash\inh{\theta P_0}\fillsyn\bid{Q}$ (\coq{fill\_d}).

\section{Look completeness is false}\label{sec:look}
% =====================================================================

\begin{lempaper}[\normalfont Look completeness,
    \texttt{subtyping-proofs.tex:2730}]
  Suppose
  $\Theta_0\vdash P_0$, $\skmod[\N]{P_0}{\M}$, $\erase{S}=P$ and
  $\inc[\theta]{\Theta_0}{\Theta}$.  If $\psi_a$ is a valid instantiation
  for declarative \sublab{ForallL} with
  \[
    \Theta\vdash^\N\tags{\Psi_a}{\syn{\psi_a}}
    \qquad
    \Psi \text{ disjoint from } \Psi_a
    \qquad
    \typsub[\N][\M][\Psi,\Psi_a]{\Theta}{
      (\syn{\theta S})[\syn{\psi_a}/\alpha]}{\bid{Q}}
    \qquad
    \Theta\vdash\inh{\theta P_0}\fillsyn\bid{Q},
  \]
  then there exist $P_a$, $\Xi$ and $\theta_a$ such that
  $\looksub[\N][\M]{\alpha}{P}{P_0}{P_a}[\Xi]$ and
  $\Theta_0,\Xi\vdash P_a$, with
  $\inc[\theta_a]{\Theta_0,\Xi}{\Theta}$,
  $\inc[\theta\equiv\theta_a]{\Theta_0}{\Theta}$ and
  \[
    \Theta\vdash\precise{\theta_a P_a}{\erase{\psi_a}} .
  \]
\end{lempaper}

\begin{claimc}\label{cl:look}
  The lemma is false at the configuration of \Cref{sec:config}, with
  $\Theta = \Theta_0$.
\end{claimc}

\paragraph{Every premise holds.}
$\Theta_0\vdash P_0$ (\coq{P0d\_wf}); $\skmod[\TY]{P_0}{\FN\TC}$
(\coq{P0d\_mode}); $\erase{S}=P$ by computation;
$\inc[\theta]{\Theta_0}{\Theta_0}$ (\coq{inc\_d}); the tag sorting
$\Theta_0\vdash^{\TY}\tags{\Psi_a}{\syn{\psi_a}}$ (\coq{psid\_tags}), with
$\Psi = \cdot$ trivially disjoint from $\Psi_a$; the fill
(\coq{fill\_d}); and the declarative premise
\[
  \typsub[\TY][\FN\TC][\cdot,\epsilon]{\Theta_0}{
    (\syn{\theta S})[\syn{\psi_a}/\alpha]}{\bid{Q}}
\]
is exactly \eqref{star}, because
$(\syn{\theta S})[\syn{\psi_a}/\alpha] = \syn{\psi_a}\to\syn{\psi_a}$
(\coq{look\_premise\_d}).

\paragraph{The conclusion fails, for every output.}
The look is deterministic here (\coq{probe\_extract\_det}), uniformly in
the marker and in every generated name --- the binder it produces is
vacuous, so it swallows them --- and its only output is
\[
  P_a \;=\; \forall\gamma.\hat\beta
  \qquad(\gamma\text{ not occurring in the body}).
\]
The lemma demands $\Theta_0\vdash\precise{\theta P_a}{\erase{\psi_a}}$,
that is
\[
  \precise{\forall\gamma.(\tunit\to\tunit)}
          {\forall\gamma.\gamma\to\gamma},
\]
which is refuted: one arrow step leaves $\tunit$ against the rigid
$\gamma$, and the only refinement rule that could take a unit to a
variable requires a \emph{defined} flexible, whereas $\Theta_0$ carries an
undefined one.  (Coq: \coq{p6l\_look\_completeness\_fails}.)
\qed

\medskip\noindent
\Cref{sec:why} explains where $\forall\gamma.\hat\beta$ comes from.

% =====================================================================
\section{Completeness of subtyping is false}\label{sec:thm}
% =====================================================================

\Cref{sec:look} breaks the \sublab{ForallL} case of this theorem's proof
(\texttt{subtyping-proofs.tex:3371}), which invokes look completeness and
nothing else at that step.  A broken proof is not a false theorem, so the
theorem gets its own refutation --- at the same configuration, with one
further ingredient.

\begin{defpaper}[\normalfont\texttt{algorithmic.tex:1423}]
  A subtyping problem is a tuple $(\Theta_0;\N;\M;P_0;P)$ where $\Theta_0$
  is well-formed, $P_0$ and $P$ are well-formed in $\Theta_0$, and
  $\skmod[\N]{P_0}{\M}$.
  %
  A solution to it is a tuple $(\inc[\theta_1]{\Theta_0}{\Theta_1};P_1)$
  such that
  $\typsub[\N][\M][\cdot]{\Theta_1}{\syn{\theta_1 P}}{\bid{P_1}}$ where
  $\Theta_1\vdash\inh{\theta_1 P_0}\fillsyn\bid{P_1}$.
\end{defpaper}

\begin{thmpaper}[\normalfont Completeness and optimality of subtyping,
    \texttt{algorithmic.tex:1447}]
  Given a subtyping problem $(\Theta_0;\N;\M;P_0;P)$, if there exists a
  solution, $\atypsub[\N][\M][P_0]{\Theta_0}{P}{P_1}{\Theta_1}$ gives its
  optimal solution $(\inc{\Theta_0}{\Theta_1};P_1)$.
\end{thmpaper}

\begin{claimc}\label{cl:thm}
  The theorem is false at the configuration of \Cref{sec:config}.
\end{claimc}

\paragraph{(1) It is a subtyping problem.}
$\Theta_0$ is well-formed; $\Theta_0\vdash P_0$ and $\Theta_0\vdash P$;
and $\skmod[\TY]{P_0}{\FN\TC}$ holds, because $\skmod[\TY]{\cdot}{\TC}$
asks for a \emph{type} and the spine of $P_0$ ends in the type
$\hat\beta$.
(Coq: \coq{$\Theta$0d\_wf}, \coq{P0d\_wf}, \coq{Pd\_wf},
\coq{P0d\_mode}.)

\paragraph{(2) It has a solution.}
Take $\theta_1 = \theta$, $\Theta_1 = \Theta_0$ and
$\bid{P_1} = \bid{Q}$.  The fill holds (\coq{fill\_d}), and one
\sublab{ForallL} step --- the \emph{untagged} one, since
$\syn{\theta_1 P}$ is the plain painting of the algorithm's input and so
carries no $\delta$ --- puts \eqref{star} underneath:
\[
\inferrule*[Lab=\sublab{ForallL}]
{
  \Theta_0\vdash\tags{\Psi_a}{\syn{\psi_a}}
  \\
  \typsub[\TY][\FN\TC][\cdot,\epsilon]{\Theta_0}
    {\syn{\psi_a}\to\syn{\psi_a}}{\bid{Q}}
  \quad\text{\eqref{star}}
}
{ \typsub[\TY][\FN\TC][\cdot]{\Theta_0}{\syn{\theta P}}{\bid{Q}} }
\]
(Coq: \coq{solution\_d}.  It is stated in the paper's judgement
$\typsub[\N][\M][\Psi]{\Theta}{\cdot}{\cdot}$, not in any auxiliary
mechanised variant.)

\paragraph{(3) Yet no algorithmic run exists.}
\[
  \nexists\, P_1\ \Theta_1.\quad
  \atypsub[\TY][\FN\TC][P_0]{\Theta_0}{P}{P_1}{\Theta_1}
\]
(Coq: \coq{probe\_no\_run}).  So the theorem fails --- a fortiori for
optimality, there being nothing to be optimal.  The trace is forced;
\Cref{sec:why} gives it.
\qed

% =====================================================================
\section{Why the algorithm fails: the marker occurs twice}\label{sec:why}
% =====================================================================

Algorithmic \silab{ForallL} picks a fresh $\alpha$ --- the \emph{marker}
--- opens the subject's binder with it, and calls the collection
judgement \emph{indexed by} $\alpha$, which emits one constraint per
\emph{occurrence} of the marker.  Here the subject is
$\forall\alpha.\alpha\to\alpha$, so the opened body is $\alpha\to\alpha$
and the marker occurs \emph{twice}.  The two occurrences sit at different
kinds of position, so they take different branches of the collection:
\[
  \looksub[\FN\TC]{\alpha}{\alpha\to\alpha}{P_0}
    {\eqcons{\forall\gamma.\gamma\to\gamma},\;
     \subcons{\TC}{\hat\beta}}[\cdot]
\]
\begin{center}\small
\begin{tabular}{@{}llll@{}}
  \toprule
  occurrence & faces, in $P_0$ & position & rule and constraint\\
  \midrule
  domain   & $\forall\gamma.\gamma\to\gamma$ & arrow-left: consistency
           & \lelab{Var}, $\eqcons{\forall\gamma.\gamma\to\gamma}$\\
  codomain & $\hat\beta$ & arrow-right: subtyping
           & \lslab{Var}, $\subcons{\TC}{\hat\beta}$\\
  \bottomrule
\end{tabular}
\end{center}
\noindent
(\coq{probe\_look\_det}: that list, deterministically.)  One marker, two
constraints --- so the solve must \emph{combine} them, and that is where
the information is lost.  With a single occurrence there would be one
constraint and nothing to lose.

\paragraph{The forced trace.}
Solving threads the accumulated pattern through the constraint list,
starting from $\Hole$:
\[\bl
  \solveeq{\Hole}{\forall\gamma.\gamma\to\gamma}
          {\forall\gamma.\gamma\to\gamma}
  \hfill \soleqlab{GhostL} \\[.4ex]
  \solvesub{\forall\gamma.\gamma\to\gamma}{\TC}{\hat\beta}
           {\forall\gamma.\hat\beta}
  \hfill \solsublab{ForallL},\;\solsublab{Check},\;\soleqlab{FlexR}
  \\[.4ex]
  \guess[\TY]{\forall\gamma.\hat\beta} = \forall\gamma.\hat\beta
\el\]
The middle line is the defect.  \solsublab{ForallL} opens $\gamma$ and
\solsublab{Check} hands $\gamma\to\gamma \consis \hat\beta$ to
\soleqlab{FlexR}, whose output \emph{is} the flexible $\hat\beta$; closing
over $\gamma$ then re-binds a \emph{vacuous} binder.  That is the $P_a$ of
\Cref{cl:look}.  Continuing with it, \silab{Arrow}'s domain consistency
$\forall\gamma.\hat\beta \consis \forall\gamma.\gamma\to\gamma$ pushes a
fresh rigid, leaving the bare $\hat\beta$ against $\gamma\to\gamma$, where
the assignment walk meets $\gamma$ with $\gamma$ occurring --- and is
stuck (\coq{probe\_solve\_det}, \coq{probe\_continuation\_stuck}).

\paragraph{One rule treats ``nothing is known here'' two different ways.}
Put the three relevant rows side by side:
\[
\inferrule*[Lab=\soleqlab{FlexR}]
{\nonflex{P}}
{\solveeq{P}{\hat\alpha}{\hat\alpha}}
\qquad
\inferrule*[Lab=\soleqlab{VacuousR}]
{~}
{\solveeq{P}{\Hole}{P}}
\qquad
\inferrule*[Lab=\solsublab{Vacuous}]
{~}
{\solvesub{P}{\M}{\Hole}{P}}
\]
A raw flexible and a ghost are the same epistemic situation: nothing is
known at that position.  The two ghost rows keep the pattern already
accumulated; \soleqlab{FlexR} replaces it by the flexible.  The collection
itself takes the other side --- on the equality branch, \lelab{FlexR}
facing a flexible input invents a \emph{fresh} flexible and constrains
against \emph{it}, rather than letting the input's flexible win.

\paragraph{And that loss is the whole defect.}
Hand \silab{ForallL} the instantiation the discarded equality determines,
namely $\erase{\psi_a} = \forall\gamma.\gamma\to\gamma$, and the run
exists:
\[
  \exists\, Q\ \Theta_1.\quad
  \atypsub[\TY][\FN\TC][P_0]{\Theta_0}
    {(\forall\gamma.\gamma\to\gamma)\to(\forall\gamma.\gamma\to\gamma)}
    {Q}{\Theta_1}
\]
(Coq: \coq{run\_exists\_at\_correct\_instantiation}).  The run it builds
is the expected one: the domain by \ulab{ForallInh} at a fresh rigid and
then \ulab{Arrow} of two \ulab{Rigid}s; the codomain
$\forall\gamma.\gamma\to\gamma \subtype_{\TC} \hat\beta$ by
\silab{ForallL}, whose collection takes \lslab{Check} and then
\lelab{FlexR}, inventing a fresh $\hat\alpha_1$; and its continuation
$\hat\alpha_1\to\hat\alpha_1 \subtype_{\TC} \hat\beta$ by \silab{Check},
\ulab{FlexR} and the assignment, which sets
$\hat\beta \assign \hat\alpha_1\to\hat\alpha_1$.  That solution is
\emph{more general} than the declarative one: $\theta\hat\beta =
\tunit\to\tunit$ factors through it by $\hat\alpha_1\mapsto\tunit$.

So every rule the run needs already exists and already works.  What the
algorithm cannot do is \emph{choose} $\forall\gamma.\gamma\to\gamma$.

% =====================================================================
\section{Suggested repair}
% =====================================================================

\soleqlab{FlexR} should yield the accumulated pattern, as its ghost twin
does; the flexible is recorded in $\Theta$ by the assignment that follows,
not by the solve's output:
\[
\inferrule*[Lab=\soleqlab{FlexR}$'$]
{\nonflex{P}}
{\solveeq{P}{\hat\alpha}{P}}
\]
The case that makes the present reading useful --- $P = \Hole$, where
returning $\hat\alpha$ lets the guess \emph{share} the flexible instead of
inventing a fresh one --- is already covered by \soleqlab{GhostL}
($\solveeq{\Hole}{Q}{Q}$).  So the two readings differ only where the
pattern already carries information, which is exactly where the present
one destroys it.

\medskip\noindent
\textbf{What has not been checked}, and should be before the change is
made: soundness of subtyping under the changed row, and the collection /
solving completeness lemmas that the subtyping completeness proof rests
on.  The mechanisation therefore does \emph{not} apply the change; it
reports it.
